<span id="klientendaten-aus-der-rzl-lohnverrechnung-exportieren" class="legacy-anchor" aria-hidden="true"></span>


:::caution[Hinweis]
Stellen Sie vor dem Export der Lohnverrechnungsdaten Ihres Klienten sicher, dass das Klientenportal korrekt eingerichtet und die notwendigen Einstellungen in den Klientenstammdaten vorgenommen wurden. [siehe Klientenstammdaten](/klientenportal/klientenportal-kanzlei/stammdaten/klient-stammdaten/stammdaten-klient/) 

:::
Öffnen Sie den gewünschten Klienten in der RZL Lohnverrechnung. 
Unter dem Programmpunkt *Bearbeiten / RZL Klientenportal / Daten bereitstellen* können Sie die Daten des Lohnklienten aus der RZL Lohnverrechnung auf das RZL Klientenportal exportieren.
