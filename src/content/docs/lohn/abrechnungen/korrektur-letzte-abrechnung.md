title: Korrektur letzte Abrechnung
program: LOHN
---

<span id="korrektur-letzte-abrechnung" class="legacy-anchor" aria-hidden="true"></span>

Im Menüpunkt *Abrechnungen / Korrektur letzte Abrechnung* kann ein bereits abgerechneter Dienstnehmer **vor** der Abrechnung des nächsten Monats korrigiert werden.

Im Gegensatz zum Programmteil [*Aufrollung*](/lohn/abrechnungen/aufrollung/) wird bei *Korrektur letzter Abrechnung* kein Hinweis auf eine berichtigte Lohnabrechnung ausgegeben. Ebenso erfolgt keine Ausweisung der Differenz zwischen der ursprünglichen und der korrigierten Lohnabrechnung im Lohnjournal.

:::note[Tipp]
Im Programmteil *Bearbeiten / Datenimport / Import Korrektur letzter Abrechnung* kann ein [Datenimport](/lohn/datenimport/) für diese Abrechnungsart durchgeführt werden.
:::
