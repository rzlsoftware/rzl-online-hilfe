# Symbolleiste

Die Symbolleiste im *RZL Lohn* bietet schnellen Zugriff auf die wichtigsten Funktionen des Programms. Die Symbole sind nachfolgend nach Themenbereichen gruppiert beschrieben.

![Image](<img/image7.png>)

## Klientenverwaltung

| Symbol                                  | Bezeichnung                                                                    | Funktion                                                                          |
| :-------------------------------------- | :----------------------------------------------------------------------------- | :-------------------------------------------------------------------------------- |
| ![Image](<img/image18.png>){width="30"} | Klient öffnen                                                                  | Öffnet die Klientenauswahl, um zu einem anderen Dienstgeber (Klient) zu wechseln. |
| ![Image](<img/image19.png>){width="30"} | Klient sichern                                                                 | ESicherung des geöffneten Klienten.                                               |
| ![Image](<img/image22.png>){width="30"} | [Klient mit E-Mail versenden](../LOHN/Verwaltung.md/#klient-mit-e-mail-senden) | Versendet die Klientendaten per E-Mail, z. B. an eine andere Kanzlei.             |

## Abrechnung

| Symbol                                  | Bezeichnung                                                                                       | Funktion                                                                                     |
| :-------------------------------------- | :------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------- |
| ![Image](<img/image9.png>){width="30"}  | [Laufende Abrechnung ohne Änderung](../LOHN/Abrechnungen/Laufende_Abrechnung_ohne_Aenderungen.md) | Startet die laufende Lohnabrechnung, ohne den Abrechnungsdialog zu öffnen.                   |
| ![Image](<img/image10.png>){width="30"} | [Laufende Abrechnung mit Änderung](../LOHN/Abrechnungen/Laufende_Abrechnung_mit_Aenderung.md)     | Startet die laufende Lohnabrechnung und öffnet den Dialog zur Änderung der Abrechnungsdaten. |
